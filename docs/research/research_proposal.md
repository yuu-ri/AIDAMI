# 学习中的结构同构与历史压缩
## ——表征误差、记忆容量及维度适应的数学研究

**副标题**：认识的商空间同构、过程状态化与资源权衡的形式化探索

> 记号说明：本文数学表达式统一采用纯文本/Unicode记号（不使用 `$...$` LaTeX 语法），以保证在任意Markdown渲染器中都能正确、一致地显示。`X/~` 表示商空间，`→`、`≅` 分别表示映射与同构，`E[...]` 表示期望。

## 一、研究背景与动机

认识与学习可以被理解为：主体通过持续交互，把外部对象及其变化规律转化为能够支持预测、判断和行动的内部表征。

本研究的核心主张是：**认识在本质上是一种同构**——主体内部表征与对象的任务相关部分之间，存在双射的结构保持映射。这一主张的动机来自认识的目的本身：

> 学习的目标不止于编码，而是为了**认识对象**。若编码不可逆，主体便无法从表征还原出识别对象所需的结构，学习便未真正完成认识。双向可逆性因此不是数学上的附加要求，而是认识目的的必然蕴含。

同构要有明确含义，须先指定比较的结构和所在范畴。外部对象与主体机构通常不在同一范畴，直接断言两者同构没有意义。正确的提法是：

```
X/~   --- φ, ≅ --->   Z
```

（商空间 `X/~` 通过映射 `φ` 与 `Z` 同构）

其中等价关系 `~` 由任务定义——任务上不可区分的对象被视为等价，商空间 `X/~` 上的同构在此意义下严格成立。

研究的核心问题由此确定：

1. 任务诱导的等价关系 `~` 是什么？商空间同构在何种条件下严格成立？
2. 同构不完全时，近似误差与表征容量之间的定量关系是什么？
3. 历史观察如何被压缩为可递推更新的状态，同时保持同构所需的结构？
4. 在给定误差要求下，需要多少样本、存储和表征自由度？

## 二、基本数学框架

### 2.1 对象、任务与表征

设：

- `X`：对象或观察空间；
- `μ`：对象上的概率分布；
- `Z`：内部表征空间；
- `e_θ : X → Z`：编码映射；
- `Y`：任务目标；
- `g_ψ : Z → Y`：预测或决策映射。

定义任务风险：

```
R(θ, ψ) = E[ ℓ( g_ψ(e_θ(X)), Y ) ]
```

任务准确性与结构同构分别衡量：预测正确不自动意味着表征与对象同构；能够重构对象也不自动意味着保留了所有指定关系。两者都成立，才构成完整意义上的认识。

### 2.2 商空间同构与近似误差

**等价关系的构造**：定义任务相关等价关系

```
x ~ x'   ⟺   对所有任务相关测试 T，T(x) = T(x')
```

在分类任务中，`~` 即类别等价；在预测任务中，`~` 由相同预测分布定义。

**严格同构**：编码 `e` 诱导商空间上的双射

```
ē : X/~   --- ≅ --->   Z/≈
```

当 `ē` 同时保持指定结构（度量、序、运算等），即为该结构范畴中的同构。

**近似同构**：严格同构不成立时，用误差量化偏差程度。在度量结构下：

```
D_geom(e) = E[ ( d_Z(e(X), e(X')) - d_X(X, X') )² ]
```

`D_geom = 0` 对应严格等距同构，`D_geom ≤ ε` 对应 `ε`-近似同构（双 Lipschitz 意义下）。

在重构结构下：

```
D_rec(e, d) = E[ ρ(X, d(e(X))) ]
```

`D_rec = 0` 对应完全可逆编码，对应同构的逆映射存在。

两类误差具有不同含义，分别对应同构在不同范畴中的近似程度。

### 2.3 历史过程的状态化

设观察序列为 `X₁, X₂, …`，内部状态满足：

```
Z_{t+1} = U_θ(Z_t, X_{t+1})
```

于是 `Z_t = E_θ(X_{1:t}, Z_0)` 是历史观察的摘要。

若任务是预测未来，则状态化须满足充分性条件：

```
P(X_{t+1:∞} | X_{1:t}) = P(X_{t+1:∞} | Z_t)   （几乎处处成立）
```

满足该条件时，`Z_t` 是历史的预测充分表征，即在"未来预测等价类"意义下，过程—状态映射是同构。这与计算力学中的因果状态（Shalizi & Crutchfield, 1999）直接对应：将产生相同未来预测分布的历史归为一类，所得最小表征即商空间同构的具体实现。

近似情形下，研究两种条件分布之间的预测损失，刻画同构的近似误差。

状态化完成后，从 `Z_t` 出发可以还原关于对象的预测判断——这正是双向可逆性（同构）在时序学习中的体现。研究中区分动态状态 `Z_t`（记录当前历史）与学习参数 `θ_t`（决定编码和更新规则）。

## 三、核心研究问题

### 问题 A：商空间同构的存在条件

研究在何种条件下，编码 `e` 在任务诱导的商空间上严格构成同构，以及同构与任务风险之间的关系：

- 同构成立时，任务风险的下界是什么？
- 分类任务（合并对象）与几何重构（区分对象）要求的等价关系相互冲突时，如何刻画两种同构之间的张力？

### 问题 B：近似同构误差与表征容量

研究同构误差 `D_geom` 或 `D_rec` 与表征容量（秩、存储比特数、状态数量）之间的定量关系：

```
D*(k) = inf{ D(e) : rank(e) ≤ k }
```

目标是建立误差关于容量的上下界，刻画"用多少容量可以达到多好的近似同构"。

### 问题 C：过程状态化的充分性与可辨识性

研究哪些历史在不损害预测同构的前提下可以合并，以及所得状态是否：

1. 足以完成预测（充分性）；
2. 可以递推更新（可计算性）；
3. 在指定意义下最小（最小性）；
4. 能从有限样本中稳定估计（可学习性）。

区分"最小充分表征已经存在"与"学习算法能够找到它"。

### 问题 D：资源—误差权衡

设算法使用 `n` 个样本、至多 `B` 比特工作内存，最终表征长度至多为 `L` 比特。研究在指定问题类 `𝒫` 上：

```
E*(n, B, L) = inf_{A ∈ 𝔄(n,B,L)} sup_{P ∈ 𝒫} E_P[ R_P(A) - R_P* ]
```

目标是建立上下界，区分学习期间的工作内存、学习完成后的模型存储、样本数量与计算时间。"时间换空间"作为资源替代关系研究，其背后的结构是：用更多训练时间（样本）换取更小的存储预算，同时保持同构误差不超过指定阈值。

### 问题 E：维度扩展、压缩与同构逼近

维度变化是同构逼近过程中的现象，研究学习在什么条件下需要：

- 增加表征方向以保存同构所需的结构信息；
- 压缩冗余或噪声方向；
- 在环境维度固定时重新组织表征以降低同构误差。

采用协方差参与率作为谱意义上的有效维度：

```
d_eff(Σ) = (tr Σ)² / tr(Σ²)      （Σ ≠ 0）
```

升维或降维本身不是目标，同构误差的降低才是目标，维度变化是实现手段。

## 四、首个可证明模型

选择**线性编码—解码模型**作为起点，给出同构框架在线性情形下的具体实现。

设中心化随机向量 `X ∈ ℝ^d` 的协方差为 `Σ`，特征值为 `λ₁ ≥ ⋯ ≥ λ_d ≥ 0`。研究秩至多为 `k` 的线性编码：

```
X̂ = WX      （rank(W) ≤ k）
```

**同构的线性实现**：秩为 `k` 的主成分投影在前 `k` 个特征方向张成的子空间上是等距同构——编码限制在该子空间内时，内积结构完整保持，逆映射存在且唯一。这是同构框架在线性情形下的最优实现。

**超出该子空间的代价**：

```
inf_{rank(W) ≤ k} E‖X - WX‖² = Σ_{j>k} λ_j
```

被省略的 `Σ_{j>k} λ_j` 正是同构误差 `D_rec` 的最优值，刻画了容量 `k` 与近似同构精度之间的定量关系。

此结果是已有的基础结论，用作研究起点，不列为创新成果。后续选择一个方向深入：

1. 有限样本和噪声下的容量选择与同构误差估计；
2. 在线学习中的工作内存约束对同构误差的影响；
3. 任务相关同构（商空间上）与完整重构同构的差异；
4. 指定学习动力学下，同构误差的演化轨迹。

## 五、与其他方法的对比

同构是本课题的核心框架，其他方法是同构在不同方向上的松弛，作为对比基准。

| 方法 | 与同构的关系 | 松弛方向 | 局限 |
|------|-------------|----------|------|
| **商空间同构**（主线） | — | — | 需指定等价关系和范畴 |
| 充分统计量 | 信息结构上的商空间同构 | 等价类由预测分布定义 | 原空间多对一，不保几何 |
| 信息瓶颈 | 放弃双射要求 | 只优化互信息，无逆映射 | 互信息 ≠ 实际存储比特数 |
| 双 Lipschitz 嵌入 | 近似同构的度量化 | 允许误差 `ε` | 不涉及信息结构 |
| Gromov-Hausdorff 距离 | 近似同构的整体度量 | 允许空间变形 | 高维下计算困难 |
| 表示相似度（CKA 等） | 同构的代理指标 | 无严格结构语义 | 不能给出误差界 |

关键区别：**同构是上表中唯一要求双射且保持指定结构的方法**。研究其他方法的目的，是在严格同构不成立时，刻画"差多少"以及"差在哪个结构上"。

## 六、文献基础与定位

| 文献方向 | 本研究中的作用 | 适用边界 |
|----------|----------------|----------|
| 抽象代数同构定理 | 商空间同构的代数基础 | 群/环同构不直接适用于统计模型 |
| 计算力学与因果状态 | 过程状态化的预测充分同构 | 预测等价不等于保存全部结构 |
| 内存—样本复杂度（Raz 等） | 资源约束下同构误差的下界 | 不直接推出复杂度随时间线性增长 |
| 信息瓶颈（Tishby 等） | 压缩与任务信息保留的对比框架 | 放弃了双射，是同构的松弛 |
| 范畴论认知模型（Phillips & Wilson） | 同构的统一形式语言 | 伴随关系弱于同构，需区分 |
| 表征内在维度（Ansuini 等） | 维度变化作为同构逼近的实验指标 | 层深维度变化 ≠ 训练时间维度变化 |

本课题以**抽象代数和范畴论**提供同构的形式语言，以**概率、线性代数与学习理论**建立首个可证明模型，以**计算力学和信息瓶颈**作为对比基准。

## 八、实验设计

实验围绕同构误差的可区分预测展开：

1. **新增任务相关因素**：增加独立因素，观察容量不足时同构误差如何变化。
2. **新增无关噪声**：增加噪声方向，检验同构误差是否因此上升。
3. **重复观察**：持续输入相同信息，检验时间增加是否降低同构误差。
4. **容量约束**：改变秩、存储精度或状态数量，测量达到目标同构误差所需的样本量。

同时记录任务风险、几何失真 `D_geom`、重构误差 `D_rec`、有效维度及存储成本。表征相似度（CKA 等）作为辅助指标，不直接解释为同构程度。

## 核心观点

> **认识是同构：主体通过学习，在任务诱导的等价类上与对象建立双射的结构保持映射。学习的数学问题，是确定这一同构在何种条件下严格成立、不完全时误差与资源的定量关系，以及历史如何被压缩为保持同构所需的最小状态。**
